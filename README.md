# LiveCoin
Aplicação web para monitoramento de cotações de criptomoedas em tempo real, gerenciamento de carteiras com valor total estimado e acompanhamento de notícias do mercado.
- **Acesse a aplicação:** [livecoin.onrender.com](https://livecoin.onrender.com)

## Funcionalidades
- **Cotações em tempo real** — monitoramento de preços ao vivo via WebSocket da Binance
- **Notícias atualizadas** — feed de notícias do mercado de criptoativos via RSS do CoinTelegraph
- **Gerenciador de carteira** — criação de portfólios pessoais e adição de moedas
